Method

      
Brightness becomes character.

      

        Each cell of the grid is measured for luminance, then matched to a glyph whose
        ink coverage is closest to that brightness. Dense marks for shadow, sparse marks
        for light. The row count is halved to compensate for monospace glyphs being
        roughly twice as tall as they are wide.
      

    


    

      

        01
        
Rasterise

        
Your image is drawn to an offscreen canvas at the exact character-grid size, with progressive halving so large photos downscale without aliasing.

        

          
        

      

      

        02
        
Measure

        
Every cell is converted to Rec.709 luminance and normalised to the full range, so a low-contrast scan reads as clearly as a punchy graphic.

        

          
        

      

      

        03
        
Ramp

        
Glyphs are ordered by measured ink coverage into a monotonic ramp, which is what keeps a gradient smooth instead of banding into steps.

        

          
        

      

    


    

      
Destinations

      
Where it lands well.

    


    

      

        
Discord

        
Wrap the art in triple backticks so it sends as a code block — that preserves the fixed-width spacing. Discord strips colour codes, so export a PNG if you want colour there.

      

      

        
GitHub README

        
Same fenced code block approach. Keep widths under about 120 characters so the art does not trigger horizontal scrolling in the rendered file view.

      

      

        
Profile bios

        
Most bios collapse runs of spaces, which shears the image. Stay under roughly 40 characters wide, or use a block charset where the glyphs carry the shape themselves.

      

      

        
Terminals & editors

        
Plain text works as-is, and mono mode is the safest choice. Download the .txt and open it anywhere that renders a monospace font.

      

    

  


  
  

    

      
Questions

      
Details that matter.

    


    

      

        Is my image uploaded anywhere? +
        

          
No. The file is read through a local blob: URL and painted onto a canvas inside this page. There is no server, no analytics, and no network request of any kind. You can load the page, disconnect from the internet, and it will still convert.

        

      


      

        How do I get a result that actually looks good? +
        

          
    
            
  • Start around 90–120 wide. Below 60 the subject turns to mush; above 160 you get detail nobody can see at a glance.
    • 
            
  • Silhouettes beat busy scenes. A subject against a plain or dark background reads far better than a cluttered photo.
    • 
            
  • Turn on Sharpen for soft or slightly blurry sources — it restores the edges that make features legible.
    • 
            
  • Flip Invert when pasting onto a dark background, otherwise the image reads as a negative.
    • 
          

        

      


      

        Why does the pasted version lose its colour? +
        

          
Colour mode copies rich HTML alongside the plain text, which is how browsers and some chat clients keep the palette. Plenty of destinations — plain README files, terminals, SMS — accept only text and drop the colour regardless.

          
Discord in particular strips colour codes from pasted text. For a guaranteed colour result, hit PNG and share the image instead.

        

      


      

        The output looks stretched or squashed. +
        

          
Monospace glyphs are taller than they are wide, roughly 1:2. The converter already compensates by halving the row count, so if it still looks off it is almost always the preview font rather than the art itself. Use A− / A+ to resize the preview, or set Density back to 1.0.

          
The copied text is unaffected by the preview size.
