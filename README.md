# PicToText — Image to ASCII Art Converter

Convert any picture, logo, or photo into text-based ASCII art ready to paste into Markdown README files, Discord chats, code comments, or terminal banners.

## Features

- **Custom Character Ramps**: Choose from standard, dense, retro retro-dither, emoji, or custom character sets.
- **Color & Inversion Modes**: Generate monochrome, high-contrast inverted, or ANSI/colored terminal ASCII representations.
- **Resolution & Aspect Control**: Tweak output character width, height scaling, and font-ratio correction.
- **Copy & Export**: One-click copy directly to your clipboard or download as `.txt` or `.html`.
- **Client-Side**: 100% processed in the browser using the HTML Canvas API.

## Getting Started

Open `index.html` in any modern web browser and select an image to convert or use it on https://jameop1.github.io/image-to-ascii-art/
